🧮 Exponential Half-Life Bit-Shift Decay
vol_decayed = vol_prior >> (elapsed / halfLife);
// Bounded linear interpolation for remainder seconds
uint256 rem = elapsed % halfLife;
vol_decayed = vol_decayed - ((vol_decayed * rem) / (halfLife * 2));

Unlike floating-point math, our algorithm executes in pure integer EVM bit shifts (SHR) with bounded remainder interpolation, ensuring zero rounding overflows and zero division-by-zero risks under Foundry fuzz runs.
